# Warehouse

A **Warehouse** egy raktárkezelő program, amely a készletek és a raktári adatok nyilvántartását segíti. Célja, hogy az árukészlet kezelése és áttekintése egyszerűbb, rendezettebb legyen.

## Funkciók

- Raktári készletek nyilvántartása
- Termékadatok rendszerezése
- Készletinformációk áttekintése

## Használat

A program telepítéséről és indításáról szóló útmutató a projekt további részleteinek ismeretében egészíthető ki.
